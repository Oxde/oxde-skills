# Comment queue

No automatic commenting. Add a candidate only when the user has a real reason to contribute.

| Status | Author | URL | Why engage | Comment type | Exact draft | Approved? | Sent? |
|---|---|---|---|---|---|---|---|

## Comment types

- add a datum
- add the missing case
- respectful disagreement
- extend a strong line
- ask the specific hard question
- field receipt
- correction
- reframe
- one-liner only when genuinely funny or true
