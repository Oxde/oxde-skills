# LinkedIn research and engagement playbook

## Research modes

### A. News / source-led post

1. Fetch the original source first.
2. Save actor, event, date, numbers, quote, caveat.
3. Find the weirdest verified detail and the social/business tension.
4. Draft from the event, not from a generic operator moral.

### B. Product / repository launch

1. Inspect the product, repo, docs, or demo.
2. Identify the dumb workflow it removes.
3. Show only the 3-4 details that prove it works.
4. Use a product screenshot/demo as the visual where possible.

### C. LinkedIn intelligence scan

Purpose: learn what is working in the AI/operator lane and find people/posts worth engaging with.

Read-only inputs:

- Boss's own recent posts + analytics.
- Search/timeline results for a small set of terms: `AI agents`, `Claude Code`, `Codex`, `agent skills`, `AI infrastructure`, relevant company/model names.
- A deliberate list of 10-20 relevant accounts, refreshed monthly.

For each candidate record:

- author + URL
- visible engagement / timing
- hook
- proof/visual
- emotion or status/control stake
- why it worked
- a boss-compatible angle, never copied text

Return 5-10 candidates, recommend at most 3 to engage with, and draft comments only after selection.

### D. Account learning

Use last 20-30 boss posts when metrics are available.

Rank by:

- engagement rate = (reactions + comments + reposts) / impressions
- comment ratio = comments / reactions
- reach multiple = impressions / follower count
- saves/sends where available

Compare top/bottom posts for hook, image, length, topic, opinion timing, and first-hour replies. Posting day/time is a last-resort explanation.

## Comment/reply taxonomy

### Comment on another post

Choose one:

- add a real datum
- add the missing case
- respectful disagreement
- extend the strongest line
- ask the hard specific question
- share a short receipt from experience
- correct a fact, briefly and kindly
- reframe the idea
- one-liner only when it is genuinely funny or true

Never restate the post or write "great post."

### Reply under boss's post

Triage:

- **lead** — real problem / possible buyer
- **substance** — useful data, question, disagreement, correction
- **peer** — high-signal person worth a real exchange
- **support** — simple praise/tag
- **noise** — spam, pitch, bad faith

Reply in that order. Answer public questions publicly. Every external action still needs boss approval.

## Current technical state

As of 2026-10-06, OpenCLI exists but its persistent LinkedIn session returns `AUTH_REQUIRED` because the `li_at` cookie is missing. Do not claim live LinkedIn scanning is currently active. Log in to LinkedIn in the persistent Chrome/Chromium session to enable the free read path.
